# Wordoff landing page

The marketing site for Wordoff, built with Next.js and Tailwind CSS and exported as static HTML.
Its colours, type and components come from the app's [design system](../DESIGN.md).

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static export to out/
```

Deployed on Vercel with `web/` as the project root. Screenshots live in `src/assets/screens/`.
